# odin-recipes
Sitio de recetas simple,  su propósito es comenzar a practicar HTML puro, dirigido como parte de "The Odin Project"
## Habilidades practicadas
- Estructura básica de documentos HTML (boilerplate)
- Organización de archivos y carpetas para un proyecto multi-página
- Enlaces absolutos y relativos, navegación entre páginas
- Uso de imágenes con atributos de accesibilidad (alt, width, height)
- Listas ordenadas y desordenadas
- Buenas prácticas de commits en Git (asunto + cuerpo)
